📄 Como gerar um PGR

      
    
        
  1. Acesse Gerador de PGR no menu lateral
    2. 
        
  2. Preencha os dados da empresa (CNPJ, endereço, CNAE)
    3. 
        
  3. Importe o PDF da empresa para preencher automaticamente
    4. 
        
  4. Selecione os GHEs e cargos correspondentes
    5. 
        
  5. Clique em Gerar PGR — o DOCX será baixado
    6. 
      

    


    

      
📋 Como registrar uma nova medição

      
    
        
  1. Acesse Medições e Amostradores → Nova Medição
    2. 
        
  2. Selecione a empresa e a OS (Ordem de Serviço)
    3. 
        
  3. Escolha o amostrador e informe a vazão calibrada
    4. 
        
  4. O sistema calcula automaticamente o tempo de coleta
    5. 
        
  5. Confirme a baixa — o amostrador vai para Laboratório
    6. 
      

    


    

      
📊 Importar demandas do Planner

      
    
        
  1. Exporte as demandas do Microsoft Planner como Excel
    2. 
        
  2. Acesse Demandas/OS → ícone de importação
    3. 
        
  3. Faça upload do arquivo Excel
    4. 
        
  4. As demandas serão importadas automaticamente
    5.
